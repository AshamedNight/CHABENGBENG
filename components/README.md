# 风险查询小程序

基于需求文档 v1.5 开发的微信小程序前端项目，参照企查查模式，包含会员体系、付费查询、付费墙、维权服务等完整商业功能。

## 项目结构

```
weiquan-miniprogram/
├── app.js                    # 小程序入口
├── app.json                  # 全局配置（路由、tabBar、导航栏）
├── app.wxss                  # 全局公共样式（蓝色主题）
├── sitemap.json              # 索引配置
├── project.config.json       # 项目配置
├── utils/
│   ├── store.js              # 数据管理工具类
│   └── request.js            # 网络请求封装
└── pages/
    ├── index/                # 首页（搜索框、VIP入口、最近查询）
    ├── complaint/            # 提交材料页（平台选择、多图上传）
    ├── result/               # 查询结果页（付费墙、维权服务操作菜单）
    ├── photo-match/          # 风险自查页（上传→相关对象列表）
    ├── vip/                  # 会员专区（权益展示、年卡套餐）
    ├── payment/              # 支付确认页（VIP/单次/维权服务）
    ├── profile/              # 我的页（头像/昵称/UID、材料单、订单）
    ├── profile-edit/         # 个人资料编辑（头像/昵称设置）
    ├── query-history/        # 查询历史记录
    ├── order-list/           # 我的订单（VIP/单次/维权服务）
    ├── complaint-detail/     # 材料单详情
    ├── service-dispute/      # 提起异议服务页
    └── service-contact/      # 联系处理服务页
```

## 核心功能

### 1. 首页（搜索主导）
- 顶部大搜索框，输入账号UID查询风险行为参考
- 风险自查入口（VIP专属，跳转风险自查页）
- VIP开通引导条（免费用户/VIP用户不同样式）
- 功能导航（提交材料/风险自查/查询进度）
- 最近查询记录（仅VIP可见）
- 隐私协议弹窗
- 免费用户点击搜索直接弹付费墙

### 2. 提交材料（永久免费）
- 相关平台选择器（底部弹出，按分类展示）
- 相关对象UID、人物照片（可选最多4张）
- 相关对象平台帐号截图（必填）
- 证据照片（必填最多9张）、说明
- 允许当事人联系开关（默认关闭）
- 提交成功后跳转"我的"页面

### 3. 查询结果（付费墙核心）
- 目标账号基础信息、风险等级标签（免费可见）
- 累计风险提示次数统计（免费可见数字）
- 历史记录：免费用户全部模糊锁定，付费用户完整展示
- 记录展示：提交人昵称（允许联系时）、材料编号、提交时间、证据图片缩略图、状态标签
- 点击记录 → 弹出操作菜单（提起异议/联系处理）→ 单独付费299元
- 付费解锁弹窗（VIP年卡开通 / 单次9.9元二选一）

### 4. 风险自查
- 上传照片 → 智能匹配 → 相关对象列表
- 相关对象展示：人物照片、匹配度、平台、累计记录数
- 点击相关对象 → 进入查询结果页（计一次查询）

### 5. 会员专区
- 蓝色主题Banner
- 4项会员权益：年卡80次查询（50次+赠30次）、完整记录、风险自查、优先服务
- 仅年卡套餐：¥399/年
- 常见问题FAQ

### 6. 支付确认
- 支持VIP年卡、单次查询、维权服务（提起异议/联系处理）三种商品类型
- 商品信息、支付明细、微信支付模拟
- 支付成功后自动开通VIP、解锁单次查询或进入维权服务页

### 7. 我的
- 用户信息区：头像（可设置）、昵称（可设置）、UID（可复制）
- 会员标识 + 查询次数卡片（VIP年卡80次）
- 我的材料单列表
- 功能菜单：查询历史、我的订单、会员专区、帮助与反馈、关于我们、联系客服

## 商业模式

| 用户类型 | 权益 | 价格 |
|---------|------|------|
| 免费用户 | 注册后可提交材料，不可使用查询功能 | 0元 |
| VIP会员 | 年卡80次查询（50次+赠30次）+ 完整记录 + 风险自查 + 优先服务 | ¥399/年 |
| 单次付费 | 解锁当前对象完整内容 | ¥9.9/次 |
| 维权服务 | 提起异议 / 联系处理 | ¥299/次 |

## 业务规则

- 免费用户不可使用任何查询功能
- 同一UID 24小时内重复查询不扣次
- 查询无结果不扣次
- VIP年卡80次查询额度，有效期一年
- 单次查询仅解锁当前对象，7天内有效
- 维权服务（提起异议/联系处理）为独立付费项，VIP不包含

## 设计规范

- 主色调：#1677FF（蓝色）
- 主色渐变：#1677FF → #0052D9
- VIP金色：#FFD700 → #FFA500
- 页面背景：#F5F7FA
- 卡片圆角：16rpx
- 按钮圆角：48rpx（胶囊形）

## 使用方法

1. 打开微信开发者工具
2. 导入项目，选择 `weiquan-miniprogram` 目录
3. AppID 选择"测试号"或使用自己的AppID
4. 点击编译即可运行

## 技术说明

- 数据层 `utils/store.js` 统一管理用户状态、查询次数、材料单、订单等数据，已接入后端API，含降级处理
- 支付流程为前端模拟，接入真实微信支付需替换 `payment.js` 中的支付逻辑
- 图片上传使用 `wx.chooseMedia`，实际项目需接入云存储
